  - 見積書

  - 領収書
  - 支払通知書

  - 管理者のみ保存可能
- 帳票の印刷画面を開いた履歴をSupabaseに保存

## PDFの保存方法

ブラウザの印刷ダイアログを使います。日本語フォントとA4レイアウトをOSの印刷機能で扱えるため、Googleドキュメントを経由しません。

1. **帳票発行**を開きます。
2. 帳票種別と元データを選択します。
3. 必要に応じて **発行元設定** を保存します。
4. **PDFとして保存**を押します。
5. 印刷ダイアログで保存先を選択します。

macOSでは、印刷ダイアログ左下の **PDF** → **PDFとして保存** を選択します。Windowsでは、プリンターに **Microsoft Print to PDF** を選択します。

> ブラウザがポップアップを停止した場合は、このアプリのポップアップを許可してください。

## DB変更

実行対象は [0007_document_issuance.sql](../supabase/migrations/0007_document_issuance.sql) です。

- `record_document_issue()` を追加
- 帳票種別・帳票元・ファイル名・発行者・発行日時を `documents` と `audit_logs` に保存

PDF本体はユーザーが選んだ端末の保存先に作成されます。クラウドストレージへのPDFアップロードは、将来のSupabase Storage連携で追加可能です。

## 動作確認

1. Supabase SQL Editorで [0007_document_issuance.sql](../supabase/migrations/0007_document_issuance.sql) を実行します。
2. アプリを再読み込みします。
3. 管理者で **帳票発行** を開き、発行元設定を入力して保存します。
4. 請求書を選び、請求データを選択します。
5. 透かしロゴ・明細・合計・下部ロゴがA4プレビューに表示されることを確認します。
6. **PDFとして保存**を押し、印刷ダイアログからPDFを保存します。
7. 保存したPDFが1ページに収まり、振込先と合計欄が重なっていないことを確認します。
8. 領収書を選び、売上データから同様にPDF保存できることを確認します。
