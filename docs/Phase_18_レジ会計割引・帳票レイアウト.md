# Phase 18 レジ会計割引・帳票レイアウト

## 実装前の確認

- 既存の `sale_items.discount_yen` / `invoice_items.discount_yen` は明細単位の割引です。
- 税額は明細割引後の金額に、発行元設定の `floor` / `round` / `ceil` を適用して計算します。
- レジ確定は `checkout_sale_with_invoice` RPCで、売上・明細・支払・請求を同じDBトランザクション内に保存します。
- 帳票はA4固定レイアウトで、変更前は明細8行、振込先1行表示、備考枠ありでした。

## 実装内容

- レジへ「割引金額（円）」と「割引率（%）」を追加しました。
- 一方を入力すると他方を無効化し、両方未入力も許可します。
- 割引率は小数第2位まで入力でき、DBには0.01%単位の整数で保存します。
- 会計全体の割引は、明細割引と税計算を反映した割引前合計へ適用します。
- お釣り、売上、支払、請求、帳票はいずれも割引後の最終合計を使用します。
- DBでも同時入力、0〜100%、割引前合計超過を検証し、割合の割引額を既存の端数処理設定で再計算します。
- 既存データは「割引なし」として補完します。
- 帳票を「小計 → 消費税 → 割引 → 合計」の順に変更しました。
- 帳票の明細を8行から9行へ、振込先を1行から2行へ増やしました。
- 帳票の備考欄を削除し、明細表と下部ロゴをA4 1ページ内で再配置しました。

## DB変更

`supabase/migrations/0011_pos_order_discount_and_document_layout.sql` を追加しました。

`sales` と `invoices` に次の列を追加します。

- `pre_order_discount_total_yen`: 会計全体の割引前合計
- `order_discount_type`: `none` / `amount` / `rate`
- `order_discount_amount_yen`: 実際に適用した割引額
- `order_discount_rate_basis_points`: 割引率（0.01%単位、率指定時のみ）

マイグレーションは `0001`〜`0010` の適用後に、Supabase SQL Editorで1回実行してください。

## 計算例

割引前合計11,000円、割引率10%の場合：

1. `11,000 × 1,000 ÷ 10,000 = 1,100円` を既存の端数設定で丸める
2. 割引額を1,100円として保存する
3. 最終合計を `11,000 - 1,100 = 9,900円` とする

2. Vercelへソースを反映します。
3. レジで割引なし、金額割引、率割引、100%割引を登録します。
4. 金額と率を同時に入力できないこと、合計超過・100%超で確定できないことを確認します。
5. 現金会計で、割引後合計を基準にお釣りが表示されることを確認します。
6. 売上詳細と自動作成された請求詳細の割引額・合計が一致することを確認します。
7. 帳票プレビューとPDFで、9明細行、2行の振込先、4段の金額欄、備考欄なし、A4 1ページを確認します。
