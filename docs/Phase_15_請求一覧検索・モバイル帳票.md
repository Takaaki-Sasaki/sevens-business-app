# Phase 15: 請求一覧の発行日検索・モバイル帳票メニュー

## 今回の変更

- ホームの「本日の会計件数」カードを選択すると、**端末の当日の日付**を発行開始日・発行終了日に設定して請求一覧を開くようにしました。
- 請求一覧の検索欄を売上履歴と同じ操作方式（条件入力後に「検索」を選択）へ変更しました。
  - 発行開始日
  - 発行終了日
  - 請求番号・顧客・件名
  - 状態
- 発行日を指定した検索では、発行日時が未設定の下書き請求は結果に含まれません。
- 日付を空欄にして「検索」、または「条件をクリア」を選択すると、下書きを含む全期間の請求を確認できます。
- スマートフォン下部メニューに「帳票」を追加しました。
  - 管理者: ホーム／レジ／顧客／売上／請求／帳票／商品／管理
  - スタッフ: ホーム／レジ／顧客／売上／請求／帳票

## データベース

DBマイグレーションはありません。既存の `invoices.issued_at`（発行日時）を検索条件に利用します。

## 動作確認

1. ホームで「本日の会計件数」カード全体を選択します。
2. 請求一覧の発行開始日・発行終了日が当日になっていることを確認します。
3. 「検索」を選択し、当日発行した請求だけが表示されることを確認します。
4. 発行日を空欄にして「検索」または「条件をクリア」を選択し、下書きを含む請求が表示されることを確認します。
5. スマートフォン幅で画面を開き、下部メニューの「帳票」から帳票発行画面が開くことを確認します。
