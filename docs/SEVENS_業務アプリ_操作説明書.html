GETTING STARTED

はじめに：開き方と画面の見方

アプリを開く

  1. Chrome / Safari / Edge で、会社から案内されたURLを開きます。
  2. 管理者から受け取ったメールアドレスとパスワードを入力します。
  3. ログインを押します。

パスワードを忘れた場合は、管理者へ連絡してください。ログイン画面から自分で再発行する機能はありません。

操作するときの約束

  • 会計・保存中は、画面を閉じたり再読み込みしたりしないでください。
  • 赤い「取消」「停止」は、内容を確認してから使います。
  • 画面上部に「オフラインです」と出たときは、通信が戻ってから再試行します。
  • 作業後は、左下の「ログアウト」を押します。

1. 分類を作る

「種別を追加」で一番上の分類を作り、必要に応じて「＋子」でサイズ・メーカーなどの中間分類を作ります。

2. 最後の分類を選ぶ

商品は、商品を置く一番下のカテゴリにだけ登録します。途中の分類には商品を置けません。

  • 商品名・数量・割引が正しい。

  • 顧客・車両の選択は必要な場合だけ行う。

支払方法と請求データの扱い

すべての支払方法

現金・カード・QR・掛売など、どの支払方法でも会計と同時に請求データを1件作成します。

売上番号と請求番号が表示されます。現金の場合は、お釣りも完了画面で確認できます。

会計を確定した後：商品の追加・変更はレジ画面では行えません。誤りがある場合は「売上履歴」で該当売上を確認し、管理者が取消を行います。

手動で請求を登録する（管理者）

  1. 「＋ 請求登録」を押す。
  2. 必要なら請求先顧客を選び、件名・支払期限を入力。顧客と請求月は任意です。
  3. 「商品（任意）」を選ぶと内容・単価・税率が入ります。商品を選ばず自由に入力することもできます。
  4. 数量・単価・割引・税率を必要に応じて直し、「＋ 明細を追加」で行を増やします。
  5. 合計を確認し「請求データを作成」。

状態を変更する（管理者）

  1. 内容確認後、下書きを「発行済み」にする。
  2. 入金を確認したら「入金済み」にする。
  3. 誤りの場合は理由を入れて「取消」。入金済みは取消できません。

検索と編集：発行開始日・発行終了日を指定すると、発行済み請求を日付で探せます。日付を空欄にして「検索」または「条件をクリア」を押すと、下書きを含めて表示します。手動登録した下書きは「請求を編集」で再保存できます（売上から作成した請求・発行済み請求は編集できません）。

期限超過：支払期限を過ぎても入金済みでない発行済み請求は、一覧・詳細で「期限超過」と表示されます。

  • パスワード再設定は、対象者を選んで新しいものを入力します。

安全のための制限：ログイン中の自分自身は、この画面から変更できません。また、最後の有効な管理者をスタッフへ変更したり停止したりすることはできません。

スマートフォンのレジと下部メニュー

画面が狭いため、商品を選ぶ画面と会計内容を切り替えて使います。画面下部のカート ○点／合計金額を押すと、会計内容が前面に開きます。

  • 管理者は、さらに「商品／管理」も使えます（図中の※）。

iPhone Safariでの入力：検索条件、預かり金、カート明細、請求登録の入力欄は、画面幅に応じて縦に並びます。入力欄を押しても画面を大きく拡大しない設計です。下部メニューに隠れそうなときは、画面を少し上へスクロールして入力してください。

毎日の基本チェック

営業開始時

  • ネット接続を確認
  • ホームで本日の状況を確認
  • 新しい商品・価格を確認

  • 必要なら顧客・車両を選択

最後に：困ったときの早見表

顧客が見つからない

顧客管理で氏名・電話番号を確認します。未登録なら、レジ内または顧客管理から新規登録します。

商品がレジに出ない

商品管理で「有効」になっているか、末端カテゴリに登録されているか、税率が選ばれているかを管理者が確認します。

会計を間違えた

会計確定後は、売上履歴で該当売上を確認します。管理者が理由を入れて取消します。履歴は残ります。

請求を発行したい

請求管理で下書きの請求を開き、内容を確認して「請求を発行済みにする」を押します。

帳票を送付したい

帳票発行でプレビューを確認し、PDFとして保存します。保存したPDFをメール添付などで送付します。
