# Phase 3 顧客・車両管理

## 実装内容

- 顧客一覧、顧客番号・氏名・電話番号・携帯番号での検索
- 顧客の新規登録、編集、論理削除（停止）
- 顧客番号のDB側自動採番（`C000001` 形式）
- 顧客ごとの車両の追加、編集、論理削除（停止）
- PCの2カラム画面とスマートフォンの縦並び画面

## DB適用順

Supabase SQL Editorで、次の順に実行してください。

1. `supabase/migrations/0001_foundation.sql`
2. `supabase/seed.sql`
3. `supabase/migrations/0002_customers_and_vehicles.sql`

`0002` は `0001` が作成する `customers` / `vehicles` テーブルに依存します。

## 操作確認

1. 初期管理者またはスタッフでログインします。
2. メニューの「顧客管理」を開きます。
3. 「顧客登録」から氏名を入力して保存します。
4. 自動採番された顧客番号を確認します。
5. 顧客を選択し、「車両を追加」から登録番号・メーカー・車種などを保存します。
6. 顧客または車両の「停止」を選び、一覧から除外されることを確認します。

停止は `deleted_at` を更新する論理削除です。過去の売上・請求・車両の関連データを物理削除しません。
