# Phase 13：レジ「その他」・商品削除・スマホ商品管理

## 今回実装した内容

- レジに、商品マスタへ登録しない自由入力の「その他」を追加
- 商品とカテゴリツリーを、過去の売上を壊さずに削除できるよう変更
- スマートフォンの画面下メニューへ、管理者向けの「商品」を追加

## DB変更（必須）

次のSQLファイルを、Supabase Dashboard の **SQL Editor** で実行してください。

[`0008_pos_other_and_product_archive.sql`](../supabase/migrations/0008_pos_other_and_product_archive.sql)

このSQLを実行するまで、画面上の「その他」の会計確定と「商品を削除」「カテゴリツリーを削除」は使用できません。

SQL実行後は、Vercelにこの変更を含むソースを反映してください。GitHub連携済みの場合は、変更をGitHubへプッシュすると自動デプロイされます。

## レジ：その他の追加方法

1. レジ画面左の「種別を選択」で **＋ その他** を押します。
2. 内容（例：緊急出張作業）、税抜単価、税率を入力します。
3. **カートに追加** を押します。
4. 通常の商品と同じように、カートで数量・割引を変更して会計を確定します。

「その他」は商品マスタへは登録されません。一方で、会計確定時には以下が売上明細へ保存されます。

- 商品コード：`OTHER`
- 入力した内容
- 数量、単価、割引、税率、金額

このため、売上履歴・売上から作成した請求・帳票でも、当時入力した内容を確認できます。

## 商品・カテゴリの削除方法

### 商品を削除する

1. **商品管理** → **商品マスタ** を開きます。
2. 削除する商品を選択します。
3. 右側の編集フォームで **商品を削除** を押し、確認画面で承認します。

### カテゴリツリーを削除する

1. **商品管理** → **カテゴリツリー** を開きます。
2. 削除するカテゴリを選択します。
3. 右側の編集フォームで **カテゴリツリーを削除** を押し、確認画面で承認します。

カテゴリツリーを削除すると、選択したカテゴリ、その配下のカテゴリ、および配下の商品がまとめてレジと検索から除外されます。

どちらも物理削除ではありません。過去の売上、請求、発行済みPDFの金額・明細は変更されません。また、削除済みのカテゴリ名・商品コードは新規登録時に再利用できます。

## スマートフォンでの商品管理

管理者でログインした場合、画面下部に次の7つのメニューが表示されます。

`ホーム / レジ / 顧客 / 売上 / 請求 / 商品 / 管理`

**商品** を押すと、PCと同じカテゴリツリー・商品マスタ管理画面を開けます。スタッフ権限には表示されません。
