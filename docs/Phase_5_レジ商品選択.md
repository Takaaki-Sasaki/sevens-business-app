# Phase 5 レジの商品選択・顧客選択

## 実装内容

- PC向け3カラム構成
  - 左：第1階層の種別
  - 中央：中間カテゴリまたは商品一覧
  - 右：顧客選択と選択中の商品
- 任意階層のカテゴリ選択とパンくず・戻る操作
- 商品名、商品コード、カテゴリパス（サイズ等）での商品検索
- 商品を押した時点で選択中商品へ追加。同じ商品は数量を加算
- 顧客番号・氏名・電話番号・携帯番号検索
- レジ画面内での新規顧客登録。登録後に選択内容を保持したまま顧客へセット
- スマートフォン用の下部固定「選択商品」ボタン

## DB変更

このPhaseに追加のSQLはありません。Phase 3・4で適用した顧客、商品、カテゴリのテーブルを読み取ります。

## 操作確認

1. 商品マスタへ有効な末端カテゴリと商品を登録します。
2. 「レジ」を開き、左の種別を選択します。
3. 中央でサイズなどを選択し、商品を押します。
4. 右の「選択中の商品」に追加され、同一商品を再度押すと数量が増えることを確認します。
5. 顧客検索または「新規登録」から顧客を選択します。
6. スマートフォン幅では下部の選択商品ボタンが表示されることを確認します。

## 注意点

選択中の商品はまだ会計前の画面状態です。ページ更新・ログアウト時には消え、売上データも作成しません。

Phase 6で、数量変更、単価変更、割引、税計算、小計・合計、支払方法、預かり金・お釣りの計算を追加します。
