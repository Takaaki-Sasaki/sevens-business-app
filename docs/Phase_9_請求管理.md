# Phase 9：請求管理

## 実装した内容

- **請求管理画面**
  - 請求番号、顧客名、件名で検索
  - 下書き、発行済み、期限超過、入金済み、取消済みで絞り込み
  - 顧客別の検索は顧客名を検索欄へ入力して実行
- **請求詳細**
  - 顧客、件名、請求月、支払期限、作成元、明細、小計、消費税、請求金額を表示
  - 売上由来か手動登録かを表示
- **手動請求登録（管理者）**
  - 顧客検索、件名、請求月、支払期限、任意の明細を入力
  - 明細ごとに数量、単価、割引、税率を指定
  - 金額と税額は画面・DBの双方で整数円として計算
  - UUIDによる再送制御で二重作成を防止
- **請求ステータス（管理者）**
  - 下書き → 発行済み
  - 発行済み → 入金済み
  - 下書き／発行済み → 取消済み
  - 期限を過ぎた未入金の発行済み請求は、一覧・詳細で「期限超過」と表示
- **論理取消**
  - 請求データを物理削除せず、取消日時・取消担当者・理由を保存
  - 入金済み請求は取消不可

## 権限

|操作|admin|staff|
|---|---:|---:|
|請求一覧・詳細の参照|○|○|
|手動請求登録|○|—|
|請求発行・入金登録・取消|○|—|

## DB変更

実行対象は [0006_invoice_management.sql](../supabase/migrations/0006_invoice_management.sql) です。

### 追加項目

`invoices` テーブルに以下を追加します。

- `issued_by`
- `cancelled_at`
- `cancelled_by`
- `cancellation_reason`

### 追加RPC

- `create_manual_invoice()`：手動請求を明細・税額込みで作成
- `issue_invoice()`：下書きを発行済みに変更
- `mark_invoice_paid()`：発行済みを入金済みに変更
- `cancel_invoice()`：請求を論理取消

## Supabaseでの適用手順

1. Supabase Dashboardの **SQL Editor** を開きます。
2. [0006_invoice_management.sql](../supabase/migrations/0006_invoice_management.sql) をすべて実行します。
3. アプリを再読み込みし、サイドバーの **請求管理** を開きます。

## 動作確認

1. 管理者でログインします。
2. **請求管理** → **請求登録** を押します。
3. 顧客を検索して選択し、明細・単価・税率を入力します。
4. **請求データを作成**を押し、請求詳細が開くことを確認します。
5. **請求を発行済みにする**、次に **入金済みにする** が動くことを確認します。
6. 別の下書きまたは発行済み請求で、取消理由を入力して取消を確認します。
7. 取消済み請求が一覧に残ること、入金済み請求は取消できないことを確認します。
