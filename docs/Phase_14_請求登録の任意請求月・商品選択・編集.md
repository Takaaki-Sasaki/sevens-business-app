# Phase 14：請求登録の任意請求月・商品選択・編集

## 実装内容

- ホームの **本日の会計件数** を押すと、請求一覧を開けるように変更
- 手動請求登録の **請求月** を任意入力へ変更
- 手動請求明細に、商品マスタから選択する **商品（任意）** を追加
- 商品選択時に、内容・単価・税率を初期値として明細へ設定
- 内容・数量・単価・割引・税率は、商品選択後も自由に編集可能
- 商品を選ばない自由記述明細も登録可能
- 下書き状態の手動請求を再度開き、編集・再保存できるように変更

## DB変更（必須）

Supabase Dashboard の **SQL Editor** で、次のファイルを実行してください。

[`0009_invoice_optional_month_and_edit.sql`](../supabase/migrations/0009_invoice_optional_month_and_edit.sql)

このSQLは、既存の `invoice_items` に任意入力可能な `product_id`・`tax_rate_id` を追加し、以下のRPCを更新・追加します。

- `create_manual_invoice`：請求月未入力時に `NULL` を保存
- `update_manual_invoice`：売上由来ではない下書き請求を更新

既存の請求データの請求月・明細・金額は変更しません。売上から自動作成した請求も従来どおりで、編集対象にはなりません。

## 操作方法

### ホームから請求一覧を開く

ホーム画面の **本日の会計件数** カード全体をクリックまたはタップします。請求一覧を開きます。

### 商品マスタから明細を選択する

1. **請求管理** → **請求登録** を開きます。
2. 明細の **商品（任意）** を選択します。
3. 商品カテゴリ階層・商品コード・商品名を確認して選びます。
4. 内容・単価・税率は初期値として入ります。必要に応じて、それぞれを変更します。

商品を選ばず、内容・数量・単価・割引・税率だけを入力することもできます。

### 請求月を空欄で登録する

請求月を空欄のまま、請求先と明細を入力して **請求データを作成** を押します。請求月は `NULL` として保存され、詳細画面では `—` と表示されます。

### 手動請求を編集する

1. **請求管理** の一覧から、手動登録した下書き請求を選びます。
2. 詳細画面の **請求を編集** を押します。
3. 内容を変更して **請求データを保存** を押します。

発行済み・入金済み・取消済み・売上から作成した請求は編集できません。会計との整合性および発行済み帳票の履歴を守るためです。

## 確認項目

1. ホームの本日の会計件数を押して請求一覧が開くこと
2. 請求月を空欄にして自由記述明細を登録できること
3. 請求月を入力して従来どおり登録できること
4. 商品マスタの選択後、内容・単価・税率が初期入力されること
5. 商品選択後に内容・単価・税率・数量・割引を変更して保存できること
6. 商品選択明細と自由記述明細を混在して保存できること
7. 下書き手動請求を編集画面で再度開き、明細を変更して保存できること
