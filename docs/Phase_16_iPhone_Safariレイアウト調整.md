# Phase 16: iPhone Safariレイアウト調整

## 対応内容

### iOS Safariの入力時拡大を防止

iPhone Safariは、文字サイズが16px未満の入力欄をタップすると画面を自動拡大します。これにより固定の下部メニューやカートボタンと入力欄が重なって見える場合があるため、スマートフォン幅では入力欄・選択欄・テキストエリアの文字サイズを16pxに統一しました。

### 狭い画面幅での入力欄配置

幅480px以下（iPhone SE〜Pro Maxを含む）では、次の横並び入力欄を縦並びへ変更しました。

- 売上履歴の検索条件
- 請求一覧の検索条件
- 請求登録時の顧客選択解除ボタン
- レジの預かり金・お釣り
- レジ明細の数量・単価・割引

これにより、入力欄の最小幅不足やラベル・ボタンとの重なりを防ぎます。

### そのほか

- ページ見出し・パネル見出しを必要に応じて折り返せるようにしました。
- 請求明細の横長表は、iPhone Safariでも横スクロール操作が安定するようにしました。
- 画面下部の固定メニューおよびカートボタンの余白設定は維持しています。

## 変更ファイル

- `src/shared/styles/global.css`

## 確認方法（iPhone Safari）

1. Safariで公開URLを開き、必要に応じて再読み込みします。
2. レジでカートを開き、数量・単価・割引・預かり金を順にタップします。
3. 売上履歴・請求管理で検索条件を表示し、日付やキーワードをタップします。
4. 請求登録で顧客検索、件名、請求月、支払期限、明細をタップします。
5. 画面の自動拡大、入力欄同士の重なり、下部メニューによる入力欄の隠れがないことを確認します。
