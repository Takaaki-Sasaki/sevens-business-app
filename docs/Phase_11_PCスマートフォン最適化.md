# Phase 11：PC／スマートフォン最適化

## 実装した内容

### PC・タブレット

- 721〜1,240pxの中間画面幅用レイアウトを追加
  - サイドバー幅・メイン余白を調整
  - レジの「カテゴリ／商品／会計」の3カラムを保ったまま、各カラムの最小幅を最適化
  - 商品カードを2列に維持し、横幅不足による意図しない折り返しを抑制
- 既存の広い画面用3カラムレジは維持しています。PCでは商品選択と会計内容を同時に確認できます。

### スマートフォン

- 720px以下ではサイドバーをモバイル下部ナビゲーションへ切り替え
  - ホーム／レジ／顧客／売上／請求を常時表示
  - セーフエリアを考慮し、iPhoneのホームインジケータと重ならない配置
- ボタンと入力欄の高さを原則44px以上に統一し、タップしやすく調整
- レジの会計内容をモバイル用ドロワーで表示
  - 画面下部の **カート n点／合計金額** を押すと、会計内容を前面表示
  - 商品選択・顧客選択・数量変更・支払方法選択・会計確定を同じドロワー内で完結
  - 背景タップまたは **閉じる** で商品選択画面へ戻る
  - 商品追加中もカート件数と合計金額を常に確認可能
- 一覧・詳細・帳票発行画面を1カラム中心に変更し、検索・明細・操作ボタンが横にはみ出しにくいように調整
- モバイルのモーダルは下部から開くシート形式にし、入力フォームを扱いやすくしました。

### 操作性・アクセシビリティ

- キーボード操作時に現在の操作位置が分かるフォーカス表示を追加
- 会計ドロワーの開閉状態をアクセシビリティ属性で通知

## 動作確認

1. PC幅（1,280px程度）で **レジ** を開き、カテゴリ・商品・会計の3カラムが同時に表示されることを確認します。
2. ブラウザの開発者ツールで幅を390pxまたは430pxにします。
3. **レジ** で商品を追加し、下部の **カート n点／合計** を押します。
4. 会計内容が前面に開き、数量変更・顧客選択・支払方法選択・会計確定が行えることを確認します。
5. 背景または **閉じる** を押し、商品選択へ戻れることを確認します。
6. 顧客・売上・請求・帳票発行も確認し、下部ナビゲーションやフォームが画面端・ホームインジケータに重ならないことを確認します。
