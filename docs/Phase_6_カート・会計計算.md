# Phase 6 カート・金額計算・会計内容

## 実装内容

- カート内の数量変更（小数第3位まで）
- 管理者だけの単価変更
- 割引額の入力
- 商品ごとの税率スナップショットと税額計算
- 小計、割引、消費税、合計の表示
- 支払方法マスタの選択
- 現金支払時の預かり金・お釣り・不足額計算
- 掛売選択時の請求自動作成予定表示

## 金額計算方針

- 金額はすべて整数円で扱います。
- 数量は内部的に1000倍した整数で保持します。例：`1.5` は `1500`。
- 単価×数量、税額、端数処理には `BigInt` を使用します。
- 税率と端数処理はSupabaseの `tax_rates` と `organization_settings.tax_rounding_mode` を参照します。
- 割引は単価×数量の金額を超えないよう計算時に上限をかけます。

## DB変更

このPhaseに追加のSQLはありません。会計確定時の売上・支払・請求の一括保存はPhase 7・8でPostgreSQL RPCとして実装します。

## 操作確認

1. レジで商品を追加します。
2. 数量、割引を変更し、小計・税・合計が変わることを確認します。
3. 管理者でログインしている場合だけ、単価欄が編集可能であることを確認します。
4. 現金を選択して預かり金を入力し、お釣りまたは不足額を確認します。
5. カード、QR／電子決済、掛売など、Seed済みの支払方法を選択できることを確認します。

## 注意点

会計内容はまだ画面内のカートであり、売上・支払・請求データは保存されません。保存ボタンの連打や通信再試行による二重売上防止は、売上をDBへ保存するPhase 7でidempotency keyとRPCトランザクションにより実装します。
