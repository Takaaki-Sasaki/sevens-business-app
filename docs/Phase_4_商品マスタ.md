# Phase 4 商品カテゴリ・商品マスタ

## 実装内容

- 任意の深さで追加できる商品カテゴリツリー
- 種別・中間カテゴリの追加、編集、停止、並び順変更
- 商品コードの自動採番または任意入力
- 商品名、末端カテゴリ、単価、税率、並び順、有効状態の管理
- 商品コード・商品名・カテゴリパスによる検索
- 商品停止時も過去データを変更しない論理停止

## DB変更

`supabase/migrations/0003_product_master.sql` をSQL Editorで実行してください。

- 商品コードを空欄登録した場合、`P000001` 形式でDBが採番します。
- 商品は末端カテゴリにだけ紐付けられます。
- 有効商品があるカテゴリには子カテゴリを追加できません。先に商品を別カテゴリへ移すか停止してください。
- 商品・カテゴリはRLSと画面の両方で管理者のみ変更可能です。

続けて `supabase/seed_product_categories.sql` を実行すると、タイヤ、オイル、バッテリー、部品、作業の初期カテゴリを登録します。これはSeed SQLなので、アプリコード内にカテゴリ固定値はありません。

## 操作確認

1. 管理者でログインし、「商品管理」を開きます。
2. 「カテゴリツリー」で初期カテゴリを確認し、必要に応じて種別または子カテゴリを追加します。
3. 「商品マスタ」タブで「商品登録」を選択します。
4. 商品コードを空欄または任意コードにし、商品名・末端カテゴリ・単価・税率を入力して保存します。
5. 商品名、商品コード、またはカテゴリで検索し、編集・停止を確認します。
